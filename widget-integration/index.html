SyntheticBrew Widget Example

This page demonstrates the SyntheticBrew embeddable chat widget.

Setup

  1. Create and test a schema in SyntheticBrew Cloud or Enterprise.
  2. Enable Accept chat requests for that schema.
  3. Use the management MCP get_embed_snippet tool to generate a complete embed.
  4. Copy the generated origin, schema name, and Chat-scoped key into the script below.
  5. Serve this file from an allowed widget origin and send a test message.

How It Works

The widget is loaded via a single <script> tag. It creates a chat bubble in the bottom-right corner. Click to open, type a message, and get AI responses streamed in real-time.

Configuration

<script src="https://YOUR_SYNTHETICBREW_ORIGIN/widget.js"
        data-schema="YOUR_SCHEMA_NAME"
        data-api-key="YOUR_CHAT_SCOPED_KEY"
        data-theme="light"
        data-position="bottom-right"
        data-title="AI Assistant">
</script>

The key is visible to every visitor. Give it only Chat scope, restrict allowed widget origins, monitor usage, and revoke it when the page is retired.
